# PPO CartPole Baseline Experiment

## Objective

Evaluate the performance of Proximal Policy Optimization (PPO) before applying the algorithm to robotic environments.

## Environment

Gymnasium CartPole-v1

## Algorithm

Proximal Policy Optimization (PPO)

## Implementation

The experiment was implemented using PyTorch.

## Purpose

This experiment provides a baseline validation of PPO learning capability before integration with Webots robotic simulation.

## Status

Completed
